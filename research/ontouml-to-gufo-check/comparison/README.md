# Comparison Turtle only

These files are the upstream gUFO example ontologies and invalid variants at
commit `f412254`. They were **not** inputs to OntoGraph's projection. They are
included so a reader can inspect the classified differences. Instance
individuals that appear only in these files, and not in the example prose,
were not modelled.

Source: https://github.com/nemo-ufes/gufo (CC BY 4.0).
