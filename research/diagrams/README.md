# Diagrams of the nine gUFO usage examples

These class diagrams are generated from the authored OntoUML JSON published in
`../ontouml-to-gufo-check/models/`. They are a reading aid, not an upstream
figure and not a claim that OntoGraph currently emits diagrams as a product
command.

Regenerate from this directory:

```text
python generate_ontouml_svg.py
```

Each case writes a static SVG (inlined on the research page via `<img>`) and a
Mermaid `classDiagram` source (`.mmd`) as a text alternative. No Mermaid
runtime is required to view the page.
