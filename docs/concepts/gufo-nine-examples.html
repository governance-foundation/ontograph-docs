Nine gUFO source-to-output demonstrations

Nine pinned gUFO examples have completed two installed Windows runs of typed source admission, generated RDF and SHACL, OWL reasoning, validation, persistence, reload and source-assisted reimport. Implementation is 9/9, full local demonstration is 9/9, and independent full-suite reproduction is 9/9. A separate reviewer repeated all 146 operations with matching normalized outcomes and artifact bytes. Inspect the independent review receipt.

The invalid examples retain their source assertions and expected diagnostic signatures. OWL consistency and SHACL conformance answer separate questions. Generated coverage shapes conform for all nine cases.

Each run executed 146 operations over 808 source assertions. The 36 candidate, admission, graph and shape artifact pairs are byte identical across runs. Independent graph isomorphism checks cover the complete source graph, including anonymous restrictions and RDF lists. Frozen oracles contain 35 entailment claims and 19 typed queries. Candidate replay binds the persisted candidate digest; source and candidate drift are rejected.

The installed binary was compiled from 1c3e2f7d4f1957cf6061b7f03386e3adaf9758e5, with SHA-256 688c5fc66d6b61963877fe5bd29324938f3cb03216eec58e0994137e0ee34a9d. Its embedded descriptor binds the verified source observation. Compiler input coverage remains partial.

The public evidence directory contains c01 through c09, each with the exact executed source, frozen oracle, typed candidate, generated graph, generated shapes and two-run verification. For example: invalid endurant source, generated graph, and expected diagnostic oracle. Full raw execution archives remain in retained repository evidence. Public downloads support inspection; they are not an installed runtime distribution.

Sources are from gUFO, pinned to f4122544133544eb4c6c467ba316302ab20b754a, under CC BY 4.0. Source authors and licensing remain attributed in each oracle and verification record. Offline OWL execution replaces the recorded remote import with the exact pinned ontology; it does not remove source axioms.

This demonstrates direct gUFO Turtle admission into typed source-derived candidates and regeneration of all source assertions. It is not a general OntoUML JSON-to-gUFO transformation. The upstream examples are Turtle sources; no original OntoUML JSON is invented.

This is bounded evidence for typed source-derived models. It does not establish accepted canonical assertions, modal rigidity or identity proofs, API parity, arbitrary target-only inverse reconstruction, a second backend, or C0-C7 acceptance. The original two-run receipt retains its historical pending-review counters; the successor independent receipt records the completed review. Comprehensive acceptance, product release and deployment remain separate gates.
