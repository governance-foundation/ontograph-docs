Reproduction and limitations​

The evidence index binds every downloadable artifact. Compiler v2 preserves all six canonical alignment states; the superseded v1 shorthand is rejected rather than silently reinterpreted. Tooling expectations are implementer-authored synthetic tests, not independently approved domain results.

Source, authoring and pilot reproduction instructions and execution epic retain the full evidence boundaries. Repository access may be required for source code; downloads above are served by this site.
